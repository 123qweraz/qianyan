输入方案

一个方案 = 解析引擎 + 码表 + 注释文档。输入法只内置解析引擎，方案由 configs/schemes/*.json 全权定义，可自由增删改。
流程：① 选解析引擎（拼音 / 英文 / 日语 / 笔顺码 / 逐笔笔画 / 拼音+笔画）→ ② 选码表（dicts/ 下的目录；在码表目录放一个 base.txt（每行「词 编码」）即可直接当码表）→ ③ 选注释文档（一份任意位置的 TSV/JSON 词典，如英文释义、日文释义或自定义码表）→ ④ 保存后立即编译生效 → ⑤ 在托盘 / 快捷键切换输入，行为完全由该方案 JSON 决定。

把你的码表放进 dicts/<名>/，最简单的做法是放一个 base.txt：每行「词 空格 编码 / 拼音」。编译后生成 data/<名>/trie。
留空 = 按全局默认规则选表（中文=zh-en、日语=jp-en、英文=en-zh、其余=zh-全局注释语言）。文件放哪都行，表名自动推导：文件名形如 zh-jp.tsv 时候选模板可用 jp 字段，否则用 en 字段显示。
← 从左侧选择一个方案，或点击「+ 新建」
