Tab 导航模式

💡 什么是导航模式？
拼音候选尚未上屏时，按一下 Tab 进入导航模式，此时候选框内的按键不再输入拼音， 而是用于删除、翻页、选词、切换模糊音等编辑操作，方便在不上屏的情况下微调候选。

进入与退出

进入 / 退出
拼音缓冲区非空时按 Tab 切换导航模式；再按 Tab 或任意普通键退出

默认按键

D — 删除末尾
删除拼音末尾一个字符并重新查词（可在快捷键设置中修改 nav_delete）
S — 模糊音切换
切换缓冲区末尾音节的模糊音：zh↔z、ch↔c、sh↔s 并重新查词（默认 nav_fuzzy）
R — 清空拼音
清空整个拼音缓冲区（默认 nav_clear）
H / L — 上一词 / 下一词
v 字形移动选择候选词，对应「选择上一词 / 选择下一词」
K / J — 上一页 / 下一页
翻动候选页，对应「翻到上一页 / 翻到下一页」
O — 上屏英文辅助
将当前候选的英文辅助内容直接上屏（CommitEnglishAux）
